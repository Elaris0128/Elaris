# 玩家種族分支清單

這份是玩家與 AI 共用的正式分支名單。
AI 不應再自行猜測種族分支，而要以這裡為準。

## 海人三支
- `潮霧之裔`
- `熾潮之脈`
- `鱗盾之裔`

## 獸人正式支系

### 十獸之環（克羅嵐）
十獸之環在玩家創角中直接展開為以下十個實際可選分支；不要把「十獸之環」本身再當成唯一可選分支。

- `逐影`
- `鷹目`
- `裂牙`
- `斑影`
- `隱耳`
- `馭嶺`
- `蟄蛇`
- `裂痕`
- `冥羽`

## 使用規則
- 玩家說 `海人 / 精靈 / 獸人 / 魔人`：AI 必須用這份清單追問。
- 玩家已經直接說出清單中的某一支：視為分支選擇完成。
- 玩家選 `獸人` 後，若選到克羅嵐方向，十獸之環必須直接展開為十個實際可選分支。

## 不要誤用舊名
- `霧沼裔 / 炭龜裔 / 隱號裔 / 炭鼬裔` 不是現行優先正式名。
- `夜角鹿裔 / 灰背犀裔 / 赤鬃鬣裔` 不應優先作為現行正式玩家支系回答。
