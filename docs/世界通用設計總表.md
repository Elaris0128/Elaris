# Elaris 世界通用設計總表

這份文件用來整理：在大量擴寫地區、國家、聚落與劇情前，哪些內容應先被定義成整個世界共通的設計。

目標不是把所有細節一次寫死，而是先把每個地方都會重複引用的底層規則固定下來，避免後面越做越多時互相衝突。

## 我們目前先確定的核心方向
- Elaris 的自然生命整體採用 `魔物生態` 概念，不再拆成普通生物與魔物兩套系統。
- 物品要從 `資源層` 延伸到 `用途層`，建立可玩的物品分類。
- 職業先做世界通用分類，再讓各國掛文化名稱。
- 戰技與術式都需要有世界共通的大類、分支與融合邏輯。
