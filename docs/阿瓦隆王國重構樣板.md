# 阿瓦隆王國重構樣板

這份文件把 `賽勒亞大陸 > 東境 > 阿瓦隆王國` 定義成第一個重構樣板區域。

## 為什麼先做阿瓦隆王國

- 它是標準國家型區域，最適合建立通用模板
- 它適合做玩家初始活動區
- 它比群島、海洋、深淵更容易承載主線、支線、教學與日常探索

## 建議落點

```text
content/world/02-continents/02-seleria/subregions/east/nations/avalon/

content/scenarios/regions/avalon/

```

## 各文件應該放什麼

### overview.md
- 阿瓦隆王國的一句定位
- 國家整體風格
- 所在位置與接壤區域
- 適合幾級玩家活動
- 玩家第一次接觸這個國家時應有的印象

### history.md
- 建國背景
- 重大轉折
- 目前與周邊勢力關係
- 哪些歷史能成為任務或衝突來源

### politics.md
- 統治結構
- 權力核心
- 主要派系
- 對外政策
- 內部矛盾

### military.md
- 軍事體系
- 治安力量
- 危機應對方式
- 玩家與軍方互動的可能性

### law-and-order.md
- 基本法律
- 禁忌行為
- 犯罪後果
- 玩家可利用或必須避免的規範

### trade-and-economy.md
- 主要產業
- 特產
- 貿易對象
- 黑市或稀有物資來源
- 適合放進背包與商店系統的物件

### culture.md
- 教育
- 服飾
- 習俗
- 社會階級
- 交通方式
- 節慶
- 語言使用情況

### religion.md
- 主要信仰
- 神祇或教團
- 社會影響力
- 與民間生活或政治的關係

### settlements.md
- 主城
- 次級城鎮
- 關鍵據點
- 每個聚落的功能定位

建議每個聚落至少寫：
- 定位
- 常住人口規模
- 能找到什麼服務
- 危險或秘密
- 適合出的任務類型

### landscapes.md
- 平原
- 森林
- 河流
- 山地
- 邊境
- 魔獸棲地
- 傳說地點

### characters.md
- 國王或統治者
- 軍方代表
- 商會代表
- 宗教人物
- 地方領主
- 新手村接引角色
- 可作為夥伴或對手的 NPC

### quest-hooks.md
- 主線任務入口
- 新手任務
- 地區委託
- 政治陰謀
- 地下勢力
- 野外危機
- 神祇或遺跡相關任務

## 阿瓦隆作為開局區的玩法定位

我建議把阿瓦隆王國定義成：

- 第一章主要活動區
- 世界觀教學區
- 基礎戰鬥與任務系統教學區
- 第一批關係網建立區

## 適合阿瓦隆承接的系統

- 新手角色出生背景
- 初始裝備與商店
- 冒險者公會委託
- 都市與野外切換
- 基礎戰鬥
- 地方聲望
- 第一個陣營選擇

## 最小可玩版本需要的內容

如果我們只做一個可玩的阿瓦隆 MVP，最低限度需要：

1. 一份 `overview`
2. 三個聚落
3. 六到十個關鍵 NPC
4. 一條主線任務
5. 三條支線任務
6. 一個野外探索區
7. 一個地下或遺跡區
8. 一套商店與物資來源
9. 一份地區遭遇表
10. 一份可供 ChatGPT 調用的開局說明

## 下一步的實際工作

接下來最合理的順序是：

1. 先寫 `content/game/12-ai-play` 的規格
2. 寫 `content/game/01-character` 的開局模板
3. 整理阿瓦隆王國的 `overview / settlements / quest-hooks`
4. 做第一個 `opening scenario`

只要這四步完成，你的專案就會從「設定資料庫」正式跨進「可玩的 ChatGPT 文字冒險原型」。
