# 第一版可玩切片

這份文件定義 Elaris 電腦文字遊戲的 `第一版最小可玩切片`。

目標不是一開始就做成全世界沙盒，而是先做出：
- 能創角
- 能開局
- 能在一個起始區域中探索
- 能接 1 到 3 條前期任務
- 能打 1 到 2 種常見遭遇
- 能取得第一批成長節點
- 能存檔再進來繼續玩

## 第一版的玩家體驗
玩家進入遊戲後，應能在 `30 到 90 分鐘` 內完整感受到：
1. 白身開局
2. 地區味
3. 第一批人脈
4. 第一個任務選擇
5. 第一場危險
6. 第一次成長或職業靠近

## 第一版推薦範圍

### 地區範圍
第一版只做 `1 個起始區域` 就夠。

最推薦先做：
- `幽語海`
或
- `港邊航務圈`

原因：
- 任務類型清楚
- 地區味強
- 同時可涵蓋探索、社交、跑腿、危險海路
- 很適合白身開局

### 身分範圍
玩家初始只能是：
- 白身
- 見習
- 跟行者
- 短工
- 候補

不直接開放：
- 高階執照
- 高階稱號
- 成熟公會核心成員

### 可選方向
第一版只需要支援：
- 種族 / 分支選擇
- 職業方向選擇
- 特質 / 缺陷 / 背景
- 起始裝備包 / 起始資源包

### 任務範圍
第一版只需完整支援：
- `3` 條開局任務
- `2` 條延伸任務
- `1` 條轉折事件

### 遭遇範圍
第一版只需完整支援：
- `2` 種人類型敵人
- `2` 種魔物型遭遇
- `1` 種首領或高壓遭遇模板

## 第一版核心循環
1. 創角
2. 落起始區域
3. AI / 系統組開局
4. 玩家在場景內輸入行動
5. 系統解析行動並更新狀態
6. AI 根據狀態敘事回應
7. 玩家取得任務 / 受傷 / 花費 / 人脈 / 聲望 / 線索
8. 進入下一場景
9. 達成成長節點
10. 存檔

## 第一版必做系統
- 角色建立
- 起始區域對應
- 開局組裝
- 場景狀態
- 任務狀態
- 玩家背包
- 狀態 / 傷勢 / 恢復
- 最基本戰鬥裁定
- 成長節點
- 存檔 / 讀檔

## 第一版可以延後的東西
- 全世界自由旅行
- 大量商店差異
- 完整 crafting 實作
- 複雜派系外交
- 超長支線
- 真正多地區動態世界時鐘

## 第一版完成標準
只要能做到以下，就算可玩：
1. 玩家能完成一名角色
2. 玩家能從起始區開局
3. 玩家能靠輸入行動推進場景
4. 玩家能接任務、交任務
5. 玩家能進入至少一場危險遭遇
6. 玩家能獲得第一個成長節點
7. 玩家能存檔並在之後回來繼續
