# 遊戲範圍與核心迴圈

## 目標

把 Elaris 做成一個：
- 單人
- 開放式
- 文字敘事
- 由 AI 主持但不亂改正典

的電腦文字遊戲。

## 核心原則

這不是完全自由亂跑的即興生成器。

它應該是：
- `規則固定`
- `世界資料固定`
- `玩家行動自由`
- `AI 敘事開放`

## 最小核心迴圈

每次遊戲推進，都應落在這個循環裡：

1. 玩家描述行動
2. 系統判斷：
   - 現在在哪
   - 有哪些可互動點
   - 目前壓力是什麼
   - 玩家身分、能力、裝備、聲望、狀態如何
3. AI 生成小說式回應
4. 系統更新：
   - 時間
   - 地點
   - 任務
   - 狀態
   - 聲望 / 執照 / 嫌疑
   - 世界時鐘
5. 進入下一次行動

## 這版最適合的起點

先做 `白身開局`。

理由：
- 玩家最容易理解
- 世界最容易回應
- 不需要一開始就處理太多高階制度
- 很適合慢慢長成職業與生活方式

## 第一版不要急著做的事

- 多人連線
- 完整地圖自由漫遊
- 全世界 NPC 即時生活模擬
- 所有地區同時開放
- 完整經濟模擬

## 第一版最值得先做的

1. 創角
2. 起始區域落點
3. 小白開局
4. 任務接取與推進
5. 戰鬥 / 社交 / 探索裁定
6. 成長與轉正
7. 存檔
