# 執行狀態模型

## 最低限度要記的東西

一個可玩的 Elaris 存檔，至少要記：

### 玩家本體
- 種族
- 分支
- 白身狀態
- 生活 / 職業方向
- 能力
- 特質 / 缺陷 / 背景
- 種族能力 / 分支能力
- 裝備
- 資源
- 狀態 / 傷勢

### 所在世界
- 當前地區
- 當前子地點
- 當前時間
- 世界時鐘
- 天候 / 異變 / 區域壓力

### 任務
- 已接任務
- 任務階段
- 委託人
- 報酬
- 失敗風險
- 追蹤中的線索

### 關係
- 聲望
- 執照 / 稱號
- 嫌疑 / 通緝
- 人脈
- 派系壓力

## 為什麼要先定這個

因為只要這層沒定好：
- AI 敘事會忘東忘西
- 任務接不起來
- 成長不會穩
- 長團一定斷
