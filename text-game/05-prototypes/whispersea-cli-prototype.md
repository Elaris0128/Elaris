# 幽語海 CLI 原型

這份原型是 `Elaris 文字遊戲` 的第一個單區可玩切片。它的目標不是一次做完整世界，而是先把一個區域做成可反覆驗證、可複製到其他區域的玩法骨架。

目前這個原型已經證明幾件事：

- 白身開局可以成立
- 單區 starter quest 可以完整推進、交付、結算
- 單次遭遇可以獨立分流，並把結果寫回玩家狀態
- 部分遭遇可以接出第二段 `遭遇後續`
- 地方 NPC、白身短工與基本補給可以接成日常循環
- NPC 好感已經成為正式狀態，可由搭話與任務交付慢慢累積
- 每個落點通常只有 `0-2 位` 地方人物會在好感達標後願意 `同行`
- 一般狀態下，你最多可帶 `2 位正式同行`
- 完成夠多任務後，地方會默認你們是一支 `小型冒險團`，同行上限提高到 `3 位`
- 少數 NPC 會在好感達標後願意 `同行`，陪你跑同一區域
- 同行中的少數 NPC 會在 `danger` 類遭遇裡給你額外援手，等於能和你一起扛硬局

## 目前支援的內容

### 開局

- 白身身分：
  - `跟行者`
  - `見習`
  - `短工`
- 起始落點：
  - `寂岩孤島`
  - `潮息海窟`
  - `靜唱索岬`
- 新遊戲時會自動掛上該落點對應的第一條 starter quest

### 任務

- 每條任務都有：
  - 多步推進
  - 正確地點限制
  - 線索累積
  - 完成後交付
  - 現金 / 物品 / 地區評價 / 職業方向結算
- 完成第一條後，可以到其他落點用 `board` 看當地任務板，再用 `take <number>` 接下一條 starter quest
- 目前已驗證可完整交付與結算的 starter quest：
  - `寂岩孤島的潮骨舊誓`
  - `潮息海窟的錯返潛路`
  - `靜唱索岬的斷索號`

### 白身生活循環

- `npcs` 可查看目前這個落點的人物
- `talk <number>` 可主動搭話
  - 第一次搭話通常會開出：
    - 線索
    - 地區評價
    - 職業方向
    - 少數情況下的物品
    - NPC 好感
  - 重複搭話則偏向地方回應，不再重複發放首次獎勵
- `relations` 可查看目前已建立的 NPC 好感
- `relations` 也會顯示哪些熟人仍替自己留著物資或裝備，讓地方人物真的有積累
- `recruit <number>` 可邀少數好感達標的 NPC 同行
- `party` 可查看目前正式同行名單、隊伍編制與誰是 `主同行`
- `focus <number>` 可切換 `主同行`
- `companion` 可查看主同行的數據、背景、擅長、偏好、裝備與留下理由
- 目前原型裡，同行者不會無故離隊；只要沒有真的踩到他們的底線，或你主動讓他們留在安全點，他們就會繼續跟著你跑
- `companion` 也會直接告訴你目前哪些補給與裝備欄正好對味，不必自己硬記
- `companion` 現在也會顯示這位同行者自己的 `成長線 / 目前階段 / 已解鎖里程碑 / 下一段進度`
- `dismiss [number]` 可讓主同行或指定同行先留在安全點
- `supplies` 可查看自己和主同行目前各自帶著什麼
- `give <number>` 可把一項身上物資交給主同行保管
- `takeback <number>` 可把主同行手上的物資收回
- `gear` 可查看主同行的 `武器 / 防具 / 飾品`
- `equipcompanion <weapon|armor|accessory> <number>` 可把身上物品正式交給主同行當裝備
- `unequipcompanion <weapon|armor|accessory>` 可把主同行目前裝上的一件裝備收回
- 若同行者仍在隊上，`danger` 類遭遇結算時會自動觸發一次援手效果
- 若同行者手上還帶著你交給他的補給，`danger` 類遭遇裡會再優先動用其中一份，替你多穩一段局面
- 若交給同行者的是他偏好的補給，`danger` 類遭遇裡效果會更好，還可能多帶出一點線索或可信度
- 若同行者身上已經有你替他配上的裝備，`danger` 類遭遇裡也會一起發揮效果，替你多撐一段局勢
- 若那件裝備剛好是他最順手的欄位，效果也會再更好一些
- 同行者現在也會有長線成長：
  - 一起 `移動 / 休整` 會累積同行步數
  - 一起扛過 `danger` 類遭遇會累積硬局默契
  - 命中 `對味補給 / 對味裝備欄` 會累積熟手默契
  - 滿足條件後會直接解鎖里程碑，讓援手變得更穩、更強
- 少數同行者在好感與里程碑達標後，還會把只交給熟人的 `同行支線` 放到當地任務板上
- 這些 `同行支線` 仍然沿用 `board / take / quest / turnin` 這一套，不需要另外背一套流程
- 同行支線完成後，除了正常報酬，也會額外再拉高該 NPC 的信任，並推進他的成長線
- 目前原型的同行物資與裝備採 `送出即留在對方身上` 的邏輯：對方暫時離隊時不會自動歸還，之後若再同行，仍會帶著那批東西
- 目前原型也不會因為單純過了一天或換個落點就讓同行者自己消失；除非你主動 `dismiss`，或之後真的碰到明寫的踩線事件
- `jobs` 可查看目前落點能接的白身短工
- `work <number>` 可完成一份短工，換取：
  - 現金
  - 小型物品
  - 地區評價
  - 職業方向
- 每份短工目前限制為 `同一天只能做一次`
- `services` 可查看當地的補給與實際可購買項目
- `buy <number>` 可直接花現金購買簡單補給
- `rest` 可讓時間往前走一格，並嘗試緩掉一條當前壓力

### 遭遇

- `encounter` 會生成單次遭遇，而不是只顯示一段風味文字
- `encounter danger` 可直接抽出 `danger` 類危險遭遇，方便驗證同行者是否真的會一起扛硬局
- 每次遭遇都會提供 3 個可選應對
- 玩家需用 `respond <number>` 做出選擇
- 某些選項不會直接把局勢收掉，而是會生成一段 `遭遇後續`
- 這類兩段式遭遇會讓玩家先處理眼前風險，再決定怎麼收尾
- 未處理遭遇時：
  - 不能移動
  - 不能接新任務
  - 不能推進任務步驟
  - 不能交付任務
- 遭遇結果會寫回：
  - 線索
  - 現金
  - 物品
  - 地區評價
  - 職業方向
  - 壓力標記

### 狀態與存檔

- `status` 看角色、位置、物資、現金、當前壓力、已開職業方向與目前遭遇
- `status` 也會顯示目前好感最高的幾位關鍵人物
- 若已有同行者，`status` 也會顯示對方目前的 `同行成長階段`
- 若隊上不只一人，`status` 也會顯示目前編制、同行數量與誰是 `主同行`
- 若已有同行者，`status` 與 `look` 都會把對方顯示出來
- 若同行者仍在場，`encounter / respond` 也會把對方是否一起出手顯示出來
- `save` 可存檔
- 主選單 `讀取存檔` 可接續遊玩
- 存檔後會保留：
  - 位置
  - 任務進度
  - 線索
  - 物品
  - 評價
  - 職業方向
  - 已搭過話的 NPC
  - 已建立的 NPC 好感
  - 目前同行中的 NPC
  - 當日做過的白身短工
  - 尚未處理完的遭遇

## 建議驗收流程

### 第一條任務完整跑通

1. 新遊戲
2. 從 `寂岩孤島` 開局
3. 用 `advance` 推進前兩步
4. `move` 到 `靜唱索岬`
5. 再用 `advance` 完成調查
6. `move` 回 `寂岩孤島`
7. `turnin` 領報酬

### 接第二條任務

1. 第一條結算後，`move` 到 `潮息海窟`
2. 輸入 `board`
3. 輸入 `take 1`
4. 再用 `quest` 確認第二條任務已掛上

### 第三條任務完整跑通

1. 新遊戲
2. 直接從 `靜唱索岬` 開局
3. 連續兩次 `advance`
4. `move` 到 `寂岩孤島`
5. 再 `advance`
6. `move` 回 `靜唱索岬`
7. `turnin`

### 遭遇分流驗收

1. 新遊戲後輸入 `encounter`
2. 確認畫面出現遭遇名稱與 3 個選項
3. 嘗試先 `move` 或 `take 1`
4. 確認系統會阻止，要求先 `respond <number>`
5. 輸入 `respond 1`
6. 確認畫面進入 `遭遇後續`
7. 再輸入一次 `respond <number>`
8. 用 `status` 確認線索、物品、評價與職業方向已寫回角色狀態

### 同行援手驗收

1. 新遊戲後先用 `talk` 與可同行 NPC 建立第一輪好感
2. 完成該落點對應的 starter quest，讓好感推到可同行門檻
3. 輸入 `recruit <number>`
4. 確認 `status` 出現同行者
5. 輸入 `encounter danger`
6. 用 `respond <number>` 處理遭遇
7. 確認畫面出現 `--- 某某一起出手 ---`
8. 用 `status` 或 `relations` 確認額外評價與壓力變動已寫回角色狀態

### 同行補給驗收

1. 招募一位已達門檻的同行者
2. 輸入 `supplies`
3. 輸入 `give 1` 把一項身上物資交給對方
4. 再輸入 `supplies`
5. 確認畫面能看到同行者手上的物資
6. 輸入 `encounter danger`
7. 用 `respond <number>` 處理危險遭遇
8. 確認畫面出現 `--- 某某動用了你交給他的補給 ---`
9. 再輸入 `supplies`
10. 確認剛剛那份補給已被消耗

### 同行裝備驗收

1. 招募一位已達門檻的同行者
2. 輸入 `gear`
3. 輸入 `equipcompanion weapon 1`
4. 再輸入 `gear`
5. 確認畫面能看到對方身上的 `武器` 已更新
6. 輸入 `encounter danger`
7. 用 `respond <number>` 處理危險遭遇
8. 確認畫面出現 `--- 某某身上的裝備也發揮了作用 ---`
9. 輸入 `dismiss`
10. 確認對方離隊時不會自動交還裝備，而是把它帶走

### 同行者面板驗收

1. 先招募一位已達門檻的同行者
2. 輸入 `companion`
3. 確認畫面會顯示：
   - 姓名
   - 同行定位
   - 好感
   - 背景
   - 風格
   - 數據
   - 擅長與注意點
   - 偏好物資與偏好裝備欄
   - 目前攜行與目前裝備
   - 目前對味配置
   - 成長線 / 目前階段 / 已解鎖里程碑 / 下一段進度

### 白身生活驗收

1. 新遊戲後輸入 `npcs`
2. 輸入 `talk 1`
3. 確認畫面會給出第一輪交談內容，並開出線索或職業方向
4. 確認畫面會同步提升該 NPC 的好感
5. 輸入 `relations`
6. 確認能看到剛剛建立的好感層級
7. 若該 NPC 屬於可同行類型，且好感達標，輸入 `recruit 1`
8. 確認 `status` 會出現同行者
9. 輸入 `jobs`
10. 輸入 `work 1`
11. 確認能拿到小額現金與地方物品
12. 輸入 `services`
13. 輸入 `buy 1`
14. 確認物品入包、現金扣除
15. 輸入 `rest`
16. 用 `status` 確認時間推進、壓力可能減少、好感摘要與狀態已被寫回

### 多同行與冒險團驗收

1. 先完成至少 3 條任務，確認畫面出現 `--- 小型冒險團成立 ---`
2. 輸入 `status`
3. 確認同行上限已從 `2` 提升到 `3`
4. 在不同落點再和另一位可同行 NPC 養到門檻
5. 依序輸入 `recruit <number>`，讓至少兩位同行進隊
6. 輸入 `party`
7. 確認畫面會顯示：
   - 目前編制
   - 隊伍人數
   - 哪一位是 `主同行`
   - 每位同行的 `留下理由`
8. 輸入 `focus 2`
9. 再輸入 `companion`
10. 確認畫面已切到第二位同行者的詳情
11. 輸入 `dismiss 1`
12. 確認指定同行離隊，其他同行仍留在隊上

### 同行偏好驗收

1. 先招募一位已達門檻的同行者
2. 用 `companion` 先看他的偏好物資與偏好裝備欄
3. 把對味物資交給他，或替他裝上對味欄位的裝備
4. 再輸入 `companion`
5. 確認畫面出現 `目前對味配置`
6. 輸入 `encounter danger`
7. 用 `respond <number>` 處理危險遭遇
8. 確認畫面除了基本援手外，還會額外提到這是他熟手的補給或最順手的欄位
9. 確認 `status` 裡的線索、評價或壓力結果比普通配置更好

### 同行成長驗收

1. 先招募一位已達門檻的同行者
2. 透過 `rest`、`move` 和 `encounter danger` 一起跑幾段路
3. 若有對味補給或對味裝備，再故意讓它們在危局裡命中一次
4. 確認畫面會出現 `--- 某某的同行成長解鎖 ---`
5. 輸入 `companion`
6. 確認畫面會顯示：
   - 成長線名稱
   - 目前階段
   - 已解鎖里程碑
   - 下一里程碑進度
7. 再輸入 `status`
8. 確認同行者旁邊也會顯示目前的成長階段

### 同行個人支線驗收

1. 從 `寂岩孤島` 開局，先完成 `寂岩孤島的潮骨舊誓`
2. 先和 `潮骨衡` 搭過話，再在交付後招募他同行
3. 一起 `rest` 或 `move` 幾次，讓他先解鎖第一段同行成長
4. 回到 `寂岩孤島` 輸入 `board`
5. 確認任務板會出現：
   - `[同行支線] 寂岩孤島的返線舊扣`
6. 輸入 `take 1`
7. 確認接任務畫面中的 `類型` 也是 `同行支線`
8. 用 `quest` 確認第一步是 `聽潮骨衡把舊扣的來路說清`
9. 完成整條任務後，確認：
   - 任務正常結算
   - `relations` 裡潮骨衡好感再提升
   - 若仍在同行，成長進度也會再往前推
